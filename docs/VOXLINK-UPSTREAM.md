# VoxLink 上游同步记录

## KAMUCL 1.0.44

核对来源：[AUGUHDAR/VoxLink 1.1.4 源码提交](https://github.com/AUGUHDAR/VoxLink/commit/40d03c65422978e057402efefafbc0350a3e2654)

当前启动器采用既有独立桌面端的 TypeScript 联机实现。本次参考公开 MOD 上游 1.1.4 的网络修复，同步到启动器适用的路径：

- 已验证可达的 STUN 节点优先；首节点不可达时继续寻找后续节点。
- 映射端口变化时更新打洞目标，包括无预测端口增量的情况。
- 短时间相同 punch_info 去重，发送失败允许重试。
- 房间更新收到 HTTP 429 后遵守 Retry-After 冷却；其他房间和 API 不被阻塞。
- 修复本地实现中 ACK 再回复 ACK 的热循环、重复启动打洞器、取消后等待不结束及计时器清理问题。

验证：本地 UDP/STUN 和 HTTP 服务器测试；不创建公开测试房间，也不上传用户日志。

公开仓库当前没有原先 app-desktop 源码。上游 MOD 专属 TURN 密钥重派、游戏内 LAN 命令和日志上传流程没有直接移植；本次不是完整 MOD 功能替换。若独立桌面端另有更新，需以其源码或协议说明继续核对。

## 默认游戏选项验证范围

菜单入口以 Minecraft 26.2 原版 Esc → 选项的两列顺序为参考，提供可持久化的常用游戏选项；世界难度、硬件相关图形后端、模组专属菜单不作为全局覆盖值。

数值转换核对本地 26.2 客户端 Options 字节码。自动验证覆盖 1.8.9、1.12.2、1.16.5、1.20.1、1.21.11、26.2 的文件格式、支持范围、FOV、亮度、鼠标灵敏度、聊天透明度和配置保留。此为配置写入与编码验证，不等同于逐个启动所有历史客户端验证。旧版不支持的字段跳过并提示；无法识别真实版本则停止同步，不按最新版猜测。
